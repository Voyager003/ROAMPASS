# 설계 · 기술 결정 기록 (프론트엔드)

기술·설계 선택이 생길 때마다 바로 한 줄씩 추가한다. README Q1(기술 선택 이유)과 Q6(서버/클라이언트 경계) 답의 원본.
형식: 날짜 | 선택 | 고려한 대안 | 이유. 결정이 바뀌면 지우지 않고 새 줄로 추가하고 이전 줄에 "→ #번호로 변경"을 단다.
Next.js 문서를 근거로 한 결정은 `node_modules/next/dist/docs/` 안의 파일 경로를 적는다.
